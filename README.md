## 📌 About the Project

**SAMS-Dashboard** is a centralized, web-based dashboard application designed to provide real-time monitoring, analytics, and management capabilities for the SAMS ecosystem.

It enables users to:
- Visualize system data  
- Monitor performance metrics  
- Manage operations  
- Access insights through a clean and responsive UI  

This project is built using a modern frontend-backend architecture to ensure scalability, performance, and ease of use.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Git  
- Node.js (v14+)  
- npm or Yarn  

### Installation

```bash
git clone https://github.com/OmkarYelsange/SAMS-Dashboard.git
cd SAMS-Dashboard
```

Install Dependencies

```
npm install
```

Start the Project

```
npm run dev
```

The application will run on:

````
http://localhost:5173
````
